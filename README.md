## IC2 Utils
Some utilities for IC2.  
Features:  
- Electric Wrench (New): The better Electric Wrench.
  It rotates machine easily from any sides, dismantles machines with left click, like the New wrench in IC2, but can be charged like an Electric Wrench.  
- Jetpack Removal Recipe: Add recipes to split jetpack from chestplates.
  By default, just place the chestplate in crafting grid. Can be configured to require a tool instead.
- Sneak to add Coils: Sneak-use coils, heat conductors or motors on a corresponding machine will install them into the machine.
